# IMU Vibration Detection and Rejection

**MathWorks Challenge Project – Project 231**

## Overview
This project focuses on detecting and reducing vibration effects in Inertial Measurement Unit (IMU) data using MATLAB and Simulink.

## Objective
To develop a simulated IMU system, introduce realistic vibration effects, and investigate techniques to detect and compensate for unwanted vibrations in accelerometer and gyroscope measurements.

## Methodology
1. IMU modelling and simulation.
2. Analysis of real-world vibration datasets.
3. Development of a vibration model.
4. Vibration detection using signal processing.
5. Vibration compensation and filtering.
6. Performance evaluation and validation.

## Tools and Technologies
- MATLAB
- Simulink
- Navigation Toolbox
- Sensor Fusion and Tracking Toolbox
- Signal Processing Toolbox
